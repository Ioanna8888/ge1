# Repository για την πρώτη εργασία του ΣΔΥ60

## Περιγραφή
Αυτό το repository χρησιμοποιείται για την οργάνωση και την ανάπτυξη της πρώτης ομαδικής εργασίας.

## Στόχοι
- Συνεργασία των μελών της ομάδας
- Οργάνωση αρχείων και εκπαιδευτικού υλικού
- Καταγραφή αλλαγών και προόδου

## Μέλη ομάδας
- ΠΑΠΑΧΡΗΣΤΟΥ ΙΩΑΝΝΑ
- ΜΑΡΓΑΡΗΣ ΒΑΙΟΣ
- ΠΕΤΡΑΚΗ ΒΑΣΙΛΙΚΗ
- ΒΑΛΥΡΑΚΗΣ ΜΑΝΟΥΣΟΣ

## Δομή αποθετηρίου
- `docs/`: τεκμηρίωση και σημειώσεις
- `src/`: κώδικας, εφόσον υπάρχει
- `deliverables/`: τελικά παραδοτέα

## Συνεργασία
Όλα τα μέλη πρέπει να περιγράφουν τις αλλαγές τους με σαφή commit messages.
